# Original app icons

These icons come from Arda Çebi's original app repositories. Each source filename is confirmed by the `Icon` property in the app's `Screen1.scm` file.

- Coby Browser: https://github.com/ardacebi/coby-browser/blob/master/source/assets/hiresiconnew.png
- Tras Tras Translator: https://github.com/ardacebi/tras-tras-translator/blob/master/assets/logo.png
- Randomer: https://github.com/ardacebi/randomer/blob/master/assets/logo.png

The site serves 168 × 168 WebP versions for the 36-pixel display size. Rotation and stacking are CSS treatments; the original artwork is preserved.
